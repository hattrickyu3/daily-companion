# 音声入力（PCとiPhone）

話したことを、議事録と同じWhisperと辞書で文字にする。つなぎ言葉（えーと・あのー）は消え、
辞書の「間違えやすい書き方」は正しい書き方に直る。AIに書き直させないので、話していない言葉は足されない。
録音は文字にしたらすぐ消す（記録には残さない）。長い話（5分より長い）はひとりメモで録る。

- 受け口：`POST /dictate`（`src/companion/web/dictate_routes.py`）。返すのは文字だけ
- 辞書は「すべての場面」の語を使う（授業だけの語は使わない）

## PC

**右Ctrlを1回押して話し、もう1回押すと、カーソルのある所に文字が入る。** メモ帳でもブラウザでもClaudeでも、どこでも使える。

- 録音中は画面の下に「● 録音中」と出る。やめるときは Esc
- 文字は「クリップボードに入れて Ctrl+V」で入れ、そのあと元のクリップボードの文字に戻す（画像などをコピーしていたときは戻らない）
- 右Ctrlを Ctrl+C のように組み合わせで使ったときや、長く押したときは録音しない
- マイクはWindowsの設定の「既定の録音デバイス」を使う（2026-10-24時点は「マイク (2- IPEVO V4K)」）
- キーを変えたいときは `.env` に `DICTATION_KEY=alt_r`（右Alt）などと書いて起動し直す
- 記録：`logs\dictation.log`

### 動かす

- **今すぐ**：`scripts\start_dictation.bat` をダブルクリック（2回押しても1つしか動かない）
- **ログインしたら自動で**：管理者のPowerShellで `scripts\register_tasks.ps1` を実行し直す（`daily-companion-dictation` が登録される）
- **止める**：タスクマネージャーで `pythonw.exe` を終了する

Webアプリ（daily-companion）が動いていないと「Webアプリにつながりません」と出る。

## iPhone

iPhoneの決まりで、ほかのアプリの入力欄に直接は入れられない。**文字をクリップボードに入れるところまで**を
ショートカットでして、入れたい所で貼り付ける。

### 作り方（「ショートカット」アプリ）

1. 右上の「＋」→ 名前を「**音声入力**」にする
2. 「**オーディオを録音**」を足す（開始：すぐに、停止：タップ時）
3. 「**URLの内容を取得**」を足す
   - URL：`https://desktop-eq9fta6.tailc0cfb5.ts.net/dictate`
   - 方法：**POST**、本文を要求：**フォーム**
   - 「新規フィールドを追加」→「**ファイル**」→ キー `audio`、値は青い「**録音されたオーディオ**」を選ぶ（「ショートカットの入力」にしない）
4. 「**クリップボードにコピー**」を足し、コピーするものを「URLの内容」にする
5. 「**通知を表示**」を足し、本文を「URLの内容」にする（何が入ったかを確かめられる）

### 動かす

ひとりメモと同じく、背面タップ・アクションボタン・「Hey Siri、音声入力」・コントロールセンターから。
背面タップの「ダブルタップ」をひとりメモにしているなら、音声入力は「トリプルタップ」にするとよい。

### うまくいかないとき

- 「送れませんでした: 録音ファイルが入っていません」→ 手順3の値が「録音されたオーディオ」になっていない
- 何も入らない → 聞き取れなかった（無音・小さい声）
- エラーで止まる → Tailscale がオフ。PCに届いた記録は `logs\web.log` の `dictation was not accepted`
