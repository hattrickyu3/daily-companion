# ひとりメモのショートカット（iPhone）

アプリを開かずに、背面タップなどからすぐ録音してPCに送り、ひとりメモにする。
PCが文字起こしと清書をして、できたら通知が届く。ひとりメモはアプリの「ひとりメモ」と、保管庫の `_授業以外\ひとりメモ` に残る（2026-10-25から）。

話しながら文字を見たいときは、アプリの「話して入力」（`/memos/talk`）をホーム画面に置いて使う。ショートカットの録音は止めるまで音声を渡さないので、話しながらは文字にできない。

- 送り先：`https://desktop-eq9fta6.tailc0cfb5.ts.net/minutes/quick`（Tailscale の https。ほかの画面と同じく、Tailscaleの中からしか届かない）
- 受け口：`src/companion/web/minutes_quick_routes.py`（フォームの `audio` に録音ファイルを入れて POST）

## 作り方

iPhoneの「ショートカット」アプリで作る。

1. 右上の「＋」を押す。いちばん上の名前を「**ひとりメモ**」にする（「メモ」だとSiriが純正のメモアプリと取り違える）
2. 「アクションを追加」→ 検索に「録音」と入れて「**オーディオを録音**」を選ぶ
   - 「オーディオの録音」の右の矢印を開き、**開始：すぐに**、**停止：タップ時** にする
3. 検索に「保存」と入れて「**ファイルを保存**」を足す
   - 保存するもの：「録音されたオーディオ」
   - 保存先を尋ねる：**オフ**
   - 保存先のフォルダ：「**このiPhone内**」に「ひとりメモ」フォルダを作って選ぶ（iCloud Driveにしない。日記と同じく手元に置くため）
   - これで、送れなかったときも録音はiPhoneに残る
4. 検索に「URL」と入れて「**URLの内容を取得**」を足す
   - URL：`https://desktop-eq9fta6.tailc0cfb5.ts.net/minutes/quick`
   - 右の矢印を開き、**方法：POST**、**本文を要求：フォーム**
   - 「新規フィールドを追加」→「**ファイル**」→ キーに `audio`、値に「録音されたオーディオ」を選ぶ
   - キーの名前は `Audio` など違っていても受け取る。大事なのは種類を「**テキスト**」ではなく「**ファイル**」にすること
   - 本文を「フォーム」ではなく「ファイル」にして「録音されたオーディオ」を入れても送れる
5. 検索に「通知」と入れて「**通知を表示**」を足し、本文に「URLの内容」を入れる
   - 「受け取りました。できたら通知します。」と出れば送れている
6. 右上の「完了」で保存する

## すぐ動かせるようにする

どれか1つでよい。

- **背面タップ**：設定 →「アクセシビリティ」→「タッチ」→「背面タップ」→「ダブルタップ」→ ショートカットの「ひとりメモ」
- **アクションボタン**（iPhone 15 Pro以降）：設定 →「アクションボタン」→「ショートカット」→「ひとりメモ」
- **Siri**：「Hey Siri、ひとりメモ」
- **ロック画面・コントロールセンター**：編集 →「コントロールを追加」→「ショートカット」→「ひとりメモ」

## 送れなかったとき

- 「送れませんでした: 録音ファイルが入っていません」と出たら、手順4の値が「録音されたオーディオ」になっていない。
  欄を消して、キーボードの上に出る青い「録音されたオーディオ」を選び直す（2026-10-24に実際に起きた。
  「ショートカットの入力」などが入っていると、背面タップから動かしたときに空になる）

- Tailscale がオフ・圏外だと、手順4でエラーになって止まる。録音は「ファイル」アプリの「このiPhone内 › ひとりメモ」に残っている
- あとでアプリの議事録の画面の「ボイスメモから作る」で、場面を「ひとりメモ」にしてそのファイルを送る
- 「送れませんでした: 〜」と出たら、ファイルが読めなかったか、長すぎる（4時間まで）

ショートカットの録音は数分くらいの短いメモ向き。長く話すときはボイスメモか Recorder Plus で録って送る。
